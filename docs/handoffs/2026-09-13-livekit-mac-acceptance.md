## Current changes

The desktop LiveKit setup accepts Project URL, API key, and API secret together. Its dedicated save request validates completeness, preserves stored values for blank credential fields, prevents connection changes during active tasks, serializes configuration changes, and rolls credentials back if saving fails. A successful response explicitly acknowledges the connection save. Saving credentials is not proof of authentication or successful inference.

Explicit Start talking unmutes an existing audio conversation. Fatal LiveKit inference errors, unexpected session closure, and room disconnection now report safe actionable failures and revoke microphone forwarding and intent submission. Audio-pump failures stop capture and surface a failure instead of silently losing input. No provider credential or raw SDK exception is exposed in the UI.

The [private Mac tester](../../voice/dev/README.md) runs the real production provider using RAM-only account details entered through a loopback page. It separates a synthetic speech round trip from physical microphone/speaker conversation. It does not expose the Linux daemon over TCP, run Hermes tasks, or establish Linux desktop/Lenovo acceptance. Closing the page expires its capture lease; repeated End actions preserve cleanup. The user entered account values privately and reported choppy real speech. No credentials were read into chat or written to evidence.

Live troubleshooting reproduced a local playback defect: the device callback consumed a single queued packet and padded its remainder with silence even when more PCM was already queued. The callback now joins packets until the device's requested frame count is filled, preserves partial packets, and inserts silence only when the queue is actually empty. Two continuity/variable-packet regressions failed before the fix and passed afterward. Actual rendered PCM still feeds echo cancellation. RTC packet arrival no longer forces the orb into Speaking; silent RTC packets are continuous, so AgentSession owns the speaking/listening state. The RTC stream is explicitly closed on teardown.
