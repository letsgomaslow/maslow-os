## Implemented behavior

Gemini tools separate app launches from task submission. Browser, Files, Hub, Terminal and standalone Codex resolve fixed application identities; shell fragments are rejected. Window observation and refocusing are distinct from process creation. Hub reports shell acknowledgement. Missing Codex points to existing setup.

Explicit delegation uses a selected/current workspace or creates a readable, collision-safe folder under `~/Projects/Maslow Voice`. Named project ambiguity is surfaced. Retry identity preserves the task and folder. One active Codex job is enforced; speech and typed corrections share exact-turn steering. Continue resumes a saved thread through a new attempt without silently replacing it. Restarted direct jobs remain interrupted until explicit Continue.

The Tasks view retains bounded activity and instruction outcomes, exact-request approvals, task/attempt/child/thread/turn identity, artifact references, Stop, Continue and folder/result actions. The model cannot approve agent requests. End/Mute affect conversation, not work. Notifications wait for quiet and expire; background-work state excludes completed tasks. Artifact paths are contained and rechecked; existence does not establish behavior. Offline results cannot open through the host desktop path.
