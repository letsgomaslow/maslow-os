Normal/extended shortcuts change the mode without replacing the provider session or resetting its maximum deadline. Ordinary activation, task submission, progress and results do not open details. Experimental GPT-Live and local controls retain their existing behavior in collapsed Advanced settings. Missing setup offers Connect Voice through the status; provider/control failure offers an explicit retry without automatic settings or provider fallback.

The saved normalized position stays stable, initially bottom right. The compact allocation remains 56 px; active and paused conversations use 88 px. Right-click, a 650 ms hold, or focused Shift+F10 opens one details card containing Conversation, Work and Settings. Dragging suppresses hold activation; Escape closes details and restores orb focus. Typed messages during pause retain both audio gates. End conversation retains the existing reset behavior. Optional latest captions and existing transcript, task steering, cancellation, results and exact approval review remain available.

Task badges prioritize approval, input, failure/interruption, completed result and running work, using symbols and words alongside color. Badge clicks synchronize the exact selected task with the daemon and show it first in Work. Passive attention updates never take focus; explicit task-view requests still open Work. Existing approval identities and explicit Approve/Deny actions remain authoritative.

## Implementation and review

[Panel.qml](../../voice/ui/Panel.qml) owns the simplified interaction, stable placement, badge priorities and details. [VoiceController.qml](../../voice/ui/VoiceController.qml) separates task/request errors from connection loss and bounds pending startup requests; a failed control process discards them so restart cannot replay activation. [The launcher](../../bin/omarchy-launch-voice) no longer summons a panel on activation or startup failure. Its discovery lock is released before the start request finishes, allowing a second shortcut to cancel connection; refresh markers created by a later operation are preserved.

[The daemon](../../voice/maslow_voice/daemon.py) owns idempotent, session-only pause and serializes controls. Pause preserves provider identity, context, transcript, project, tasks and the original 30-minute deadline. Normal inactivity expiry is suspended while paused; lock and the maximum still end the session. Session epochs and local guards stop late events from replacing paused status. An interruption clears output activity, increments a brief acknowledgement sequence and returns an active conversation to listening.

[Audio transport](../../voice/maslow_voice/audio.py) gates capture and output synchronously before awaiting provider cancellation, flushes queues and invalidates interrupted generations. Delayed capture callbacks and output remainders cannot cross pause/resume. Playback amplitude comes from PCM actually consumed by output, with bounded work deferred outside callbacks. Separate `input_level` and `playback_level` are coalesced through the daemon's existing bounded publication; legacy `level` is retained. Native Google/LiveKit interruption is awaited before resume. OpenAI input clearing is acknowledged before resume and response metadata identifies fresh generations; timeout keeps the local gates paused. These are additive internal interfaces, with no new dependency, credential flow, persistent task schema or fallback provider.

[VoiceOrb.qml](../../voice/ui/VoiceOrb.qml) and [VoiceOrb.frag](../../voice/ui/VoiceOrb.frag) implement an original blue fluid silhouette and shared native eyes/face. Listening follows input; speaking follows output; thinking contracts and focuses. Interruption immediately stops speech deformation; completion gets one brief reaction. Reduced motion freezes deformation and uses static expressions, symbols and status. Geometry remains within the allocation. Native review found that cached ShaderEffect instances could render while retaining Uncompiled status, so fallback selection uses an actual Error rather than requiring Compiled. Fresh captures verify the GPU path with the Canvas hidden, as well as the software path.

Two subagents handled independent daemon/session and audio/provider work. The coordinating agent reviewed integration, fixed launcher discovery and UI/controller edge cases, and performed final native verification.
