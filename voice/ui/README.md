# Maslow Voice plugin

The kept-loaded `maslow.voice` plugin owns one layer-shell surface within the existing shell. Its input mask covers the orb, status, task badge and explicitly opened details card. Ordinary clicks and the existing normal/extended shortcuts start, pause or resume Google Live, native LiveKit Expressive and OpenAI Realtime without opening details. Activation while connecting cancels startup. Changing shortcut modes retains the provider session and original maximum deadline. Experimental GPT-Live and local modes retain their existing start/end behavior and connection controls in Advanced settings.

The ready character uses the 56-pixel allocation; conversations, including paused conversations, use 88 pixels. It stays at its saved normalized position, initially bottom right. Dragging preserves display bounds and saves the position; Reset orb position restores bottom right. Labels choose space above or below the orb so they stay separate at the top edge. The configured display selects an output, falling back to the first available one. Lock immediately hides the surface and ends Voice.

Right-click, a 650 ms hold, or Shift+F10 while the orb is focused opens Conversation details. Dragging suppresses hold activation. Escape closes details and restores orb focus. Conversation contains the transcript, optional latest caption, typed input, Pause/Resume and End conversation. Typed messages while paused leave both audio directions paused. Work keeps the existing progress, steering, cancellation, results, exact approval identities and export review. Clicking a Work badge also selects that exact task in the daemon and puts its review first. Settings opens the existing connection and preference controls; Advanced settings starts collapsed. Missing setup shows Connect Voice; clicking that status opens setup. Failures show Connection lost with retry, never automatically open settings or switch providers.

Badge priority is approval, required input, failure/interruption, completed result, then running/proposed work. Symbols and words accompany color. Passive task events update badges without opening or focusing a panel; an explicit task-view request still opens Work. Completion reacts once when a task transitions to completed, rather than when old history is loaded.

`VoiceController.qml` starts `omarchy-voice-control --watch`, reconciles schema-1 snapshots and writes JSON requests to its input pipe. A bounded queue holds explicit requests only until that pipe starts; process failure discards it so reconnect/restart cannot replay activation. Generic task/configuration errors remain separate from lost-control-connection status. Credentials stay out of arguments and secret fields clear after confirmed save. Fixture mode records requests without contacting the production controller and visibly labels the surface UI preview.

Pause is session-only and daemon-owned. It preserves provider identity, context, transcript, project and separately running tasks; normal inactivity is suspended while paused, but the existing 30-minute maximum and lock shutdown remain. Audio controls are serialized. The transport gates input/output before network cancellation, flushes bounded queues and invalidates old generations. Native AgentSession interruption completes before resume; OpenAI additionally waits for its input-clear acknowledgement and accepts only fresh response generations. A cancellation timeout keeps the local pause gates closed.

The orb and Voice controls follow the active desktop palette through the shared `qs.Commons.Color` singleton, including live theme changes and popup overrides. The body gradient uses the theme accent; the face and focus indicator choose contrasting ink. GPU shader uniforms and Canvas repaint hooks use the same colors, including while paused or reduced motion is enabled.

The fluid character shares its native face and deformation across GPU and Canvas renderers. Ready blinks occasionally; listening reacts to input, thinking focuses and contracts, speaking reacts to PCM actually consumed by the local output callback, interruption stops output deformation immediately, and completion gets one brief bounce. The capture indicator is independent of speech. Reduced motion freezes geometry and uses static expressions, symbols and status text. Legacy microphone `voice.level` remains available, with separate `input_level` and `playback_level`; meter publication stays bounded and coalesced outside audio callbacks.

Compile `VoiceOrb.frag` with the target Qt `qsb --glsl "100 es,120,150"` into `VoiceOrb.frag.qsb`. `MASLOW_VOICE_GPU_SHADER=0` selects Canvas; Qt software rendering does so automatically. A failed shader compilation also selects the fallback. No new runtime dependency is required.

Run `bash test/shell.d/voice-test.sh`, `node voice/tests/ui-controller-test.mjs`, and `bash test/shell.d/voice-launch-test.sh` with the pinned Voice Python environment. `voice/tests/ui-preview.qml` exercises the real Panel without connecting accounts; IPC exposes activation, pages, state, task badge, captured requests and layout geometry. Copy `ui/` and the preview into a common temporary Quickshell config root, changing its import to `"./ui"`. Expose the installed shell Commons module under the temporary root too, for example with a `Commons` symlink to `/usr/share/omarchy/shell/Commons`, so `qs.Commons` resolves. Always stop the owned fixture after checks. Weston alone lacks layer-shell; native Panel verification requires the actual layer-shell compositor or nested Sway on headless Weston.

`voice/tests/orb-preview.qml` renders both allocations and eight states without constructing a controller. Copy it to the same temporary root with import `"./ui"`; set `GALLERY_OUTPUT` to save a PNG and exit automatically. `REDUCED=1` renders reduced motion. `THEME_COLORS` supplies raw test colors TOML and `THEME_NAME` labels the palette; the fixture applies it after the shared startup read. These fixtures prove native rendering and request delivery, not account authentication or physical microphone/speaker behavior. The dated handoff records remaining acceptance gates, including LiveKit Expressive's pending status.
