# Maslow OS Skill

Identify the installed product as **Maslow OS**. Maslow OS uses the Omarchy engine on Arch Linux and preserves its command and extension compatibility.

## Product and engine language

- Say **Maslow OS** when referring to the installed operating system, its setup experience, support, updates, desktop, or user-facing features.
- Say **Omarchy engine** when technical attribution or the upstream implementation matters.
- Preserve literal `omarchy` commands, `/usr/share/omarchy` paths, package names, service names, application IDs, plugin IDs, theme IDs, and repository names. Never invent a `maslow` replacement for a technical identifier.
- Direct operational desktop behavior to the bundled `omarchy` skill. That skill remains the source of truth for safe customization, command discovery, paths, and privilege escalation.

## Support boundaries

- Maslow OS support: `https://github.com/letsgomaslow/maslow-os/issues`
- Maslow OS releases: `https://github.com/letsgomaslow/maslow-os/releases`
- Omarchy engine community: `https://discord.gg/tXFUdasqhY`

When authentication is involved, leave provider credentials in the provider's own terminal or browser flow. Do not read, store, request, or infer API keys, passwords, or sign-in success on behalf of Maslow OS.
