# Клавиатура, мышь, тачпад

Hyprland позволяет настраивать все ваши вводы в мельчайших деталях. Можно сделать повтор клавиатуры сверхзвуковым или заставить тачпад использовать естественную прокрутку. Всё это изменяется в `~/.config/hypr/input.lua`, куда также можно попасть через _Настройка > Ввод_ в меню Omarchy (`Super + Space`). Всё, что вы зададите там, заменяет умолчания Omarchy.

Вот пример:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Все [параметры ввода](https://wiki.hypr.land/Configuring/Basics/Variables/#input) можно увидеть на вики Hyprland по вводам.

CapsLock работает как обычный Caps Lock, а `Shift + CapsLock` — это compose-клавиша для [быстрых эмодзи](07-hotkeys.md#quick-emojis) и [других дополнений](07-hotkeys.md#quick-completions). Если вы предпочитаете compose-клавишу в другом месте, замените `omarchy:shift_caps_compose` в `kb_options`. Например, это перемещает compose-клавишу на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жесты тачпада

Вы также можете включить [жесты тачпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), например свайп тремя пальцами для смены рабочих пространств:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

На ноутбуках Dell XPS с тактильным тачпадом силу нажатия также можно задать как низкую, среднюю или высокую в разделе _Действия > Оборудование > Вибрация тачпада_.

### Ввод на китайском, японском и других языках

Когда установщик спрашивает клавиатуру, выберите японский, корейский, китайский (упрощённый, Pinyin), Тайвань (Zhuyin) или Гонконг (Cangjie). Omarchy автоматически настраивает клавиатуру и способ ввода, в том числе при первом запуске без сети. Японский использует Mozc, корейский — стандартный двухнаборный Hangul, упрощённый китайский — Pinyin, Тайвань — стандартную раскладку Zhuyin в Chewing, а Гонконг — Cangjie с гонконгскими формами иероглифов. Японский (US-клавиатура) даёт Mozc с раскладкой US. Клавиши Hangul, Zhuyin и Cangjie сохраняют стандартные позиции даже при наборе латиницы в Dvorak, Colemak или AZERTY. Если Hangul или Chewing уже добавлен, снимите и верните выбор в _Настройка > Ввод текста > Методы ввода_, чтобы перенести клавиши; Omarchy не меняет уже используемый способ ввода.

Ввод начинается в латинском режиме. Нажмите `Super + I`, чтобы перебрать настроенные методы ввода, и `Super + Shift + I`, чтобы перебрать в обратном направлении. Коснитесь `Shift` сам по себе, чтобы выйти из метода ввода вроде пиньинь в латинские буквы, и коснитесь его снова, чтобы вернуться, как работают Sogou, Microsoft Pinyin и macOS; `Shift` плюс буква по-прежнему вводит заглавную. На японских клавиатурах 全角/半角 переключает ввод, 変換 включает его, а 無変換 выключает. В корейском 한/영 переключает Hangul, а 한자 преобразует в Hanja — и с отдельными клавишами, и когда клавиатура, как на многих ноутбуках, посылает Right Alt и Right Ctrl; поэтому здесь это не обычные модификаторы, а диктовка с удержанием остаётся на F9. `Ctrl + Space` остаётся доступным для Tmux и Herdr; `Shift + CapsLock` остаётся compose-клавишей.

Индикатор клавиатуры появляется справа на панели, когда у вас несколько раскладок клавиатуры или методов ввода. Нажмите на него, чтобы переключить языки ввода; японский отображает あ для хираганы. Для выбора японских символов переключитесь на японский, введите слово, например `nihongo`, затем дважды нажмите Space. Нажмите Enter, чтобы принять выбор. Если у вас также несколько раскладок клавиатуры, щёлкните индикатор правой кнопкой, чтобы перебрать их.

Используйте _Настройка > Ввод текста > Раскладки клавиатуры_, чтобы выбрать раскладки, например английский и французский, из тех же вариантов, что предлагались при установке. Используйте _Настройка > Ввод текста > Методы ввода_, чтобы выбрать, какие движки композиции активны. Оба средства выбора открываются внутри меню Omarchy с отмеченными текущими выборами. Щёлкните или нажмите Enter, чтобы переключить вариант; каждое изменение применяется немедленно. Снятие выбора метода ввода удаляет его из цикла, не удаляя его из системы; клавиатура остаётся доступной.

Выполните `omarchy setup keyboard` или `omarchy setup input`, чтобы открыть те же средства выбора. Чтобы добавить один язык из командной строки, используйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing`, `cangjie5`. Ваши пользовательские клавиши переключения сохраняются. Для альтернативных раскладок движка или клавиш установите `fcitx5-configtool` командой `omarchy pkg add fcitx5-configtool` и запустите его из терминала. Выбор языка ввода не изменяет язык рабочего стола. Quick, Boshiamy и Array входят в пакет Cangjie и появляются в выборе способов ввода. Выбор японского, корейского или китайского в _Настройка > Язык_ добавляет способ ввода, если ещё ни одного нет.

Используйте `Super + I`, чтобы перебирать методы ввода или раскладки клавиатуры, и `Super + Shift + I`, чтобы идти в другую сторону, так что при трёх настроенных можно перемещаться между двумя соседями. Индикатор ввода появляется справа на панели только тогда, когда настроено больше одного метода ввода или раскладки. Эта привязка рабочего стола работает наряду с вашими существующими клавишами переключения Fcitx; её можно переопределить в `~/.config/hypr/bindings.lua`. Движки ввода и последовательности compose используют службу [Fcitx5](https://fcitx-im.org/), уже работающую в каждой сессии.

### Использование ALT как SUPER

На некоторых клавиатурах неудобно использовать основную мета-клавишу (клавишу Windows/cmd) как SUPER. Это можно изменить на ALT с помощью следующего изменения:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
