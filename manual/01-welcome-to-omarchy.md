# Welcome to Maslow OS

Maslow OS is an opinionated Linux environment for AI builders and operators. It is based on [Omarchy](https://omarchy.org/), [Arch Linux](https://archlinux.org/), the [Hyprland](https://hypr.land/) tiling window manager, and the [Quickshell](https://quickshell.org/) desktop construction kit.

It combines practical developer tools with a coherent desktop designed for deliberate work: clear defaults, fast navigation, visible system state, and compatible Omarchy commands rather than a second competing engine.

The workflow is terminal-forward and keyboard-driven. That may feel unfamiliar at first, but the manual maps the core actions and keeps the underlying Arch and Omarchy behavior visible.

Maslow OS does not hide its Linux foundation. Existing Omarchy documentation, command names, configuration paths, and extension conventions remain applicable unless a Maslow-specific note says otherwise.
