# යතුරුපුවරුව, මූසිකය, ට්‍රැක්පෑඩ් එක

Hyprland ඔබේ ඇතුලත් කිරීම් ඉතා සවිස්තරාත්මකව වින්‍යාස කිරීමට ඔබට ඉඩ සලසයි. ඔබට යතුරුපුවරුව නැවත නැවත කිරීම අතිශයෝක්තියක් තරම් වේගවත් ලෙස වෙනස් කිරීමට හෝ ට්‍රැක්පෑඩ් එකට ස්වභාවික අනුචලනය භාවිතා කිරීමට දැමිය හැක. ඔබ එ සියල්ල `~/.config/hypr/input.lua` තුළ වෙනස් කරන අතර, ඔබට Omarchy මෙනුවේ (`Super + Space`) _සැකසුම > ඇතුලත් කිරීම_ හරහාද එයට ළඟා විය හැක. එහි ඔබ සැකසන ඕනෑම දෙයක් Omarchy හි පෙරනිමියන් ආදේශ කරයි.

මෙන්න උදාහරණයක්:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

ඔබට ඇතුළත් කිරීම් සඳහා Hyprland විකිහි [සියලු ඇතුලත් කිරීමේ විකල්ප දැකිය හැක](https://wiki.hypr.land/Configuring/Basics/Variables/#input).

CapsLock සාමාන්‍ය Caps Lock ක්‍රියා කරන අතර, `Shift + CapsLock` වේ රචනා යතුර [වේගවත් ඉමෝජි](07-hotkeys.md#quick-emojis) සහ [වෙනත් සම්පූර්ණ කිරීම්](07-hotkeys.md#quick-completions) සඳහා යතුර. ඔබ රචනා යතුර වෙනත් තැනක තිබීමට කැමති නම්, `kb_options` හි `omarchy:shift_caps_compose` ආදේශ කරන්න. උදාහරණයක් ලෙස, මෙය රචනා යතුර දකුණු Alt වෙත ගෙන යයි:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### ට්‍රැක්පෑඩ් ඉංගිය

ඇඟිලි තුනක් සමඟ සැලීමෙන් වැඩබිම් වෙනස් කිරීම වැනි, ඔබට [ස්පර්ශ පෑඩ් ඉංගි](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/)ද ක්‍රියාත්මක කළ හැක:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

ඇඟිලි හප්ටික් ස්පර්ශ පෑඩ් එකක් ඇති Dell XPS ලැප්ටොප් වල, ඔබට _ක්‍රියාත්මක > දෘඩාංග > ස්පර්ශ පෑඩ් හැප්ටික්ස්_ යටතේ ක්ලික් කිරීමේ ශක්තිය අඩු, මැද, හෝ ඉහළ ලෙසද සැකසිය හැක.

### චීන, ජපන්, සහ වෙනත් භාෂා වලින් ටයිප් කිරීම

ස්ථාපකය යතුරුපුවරුව විමසන විට ජපන්, කොරියානු, චීන (සරල, Pinyin), තායිවාන් (Zhuyin) හෝ හොංකොං (Cangjie) තෝරන්න. Omarchy පළමු නොබැඳි ආරම්භයේදීත් යතුරුපුවරුව සහ ආදාන එන්ජිම ස්වයංක්‍රීයව සකසයි. ජපන් සඳහා Mozc, කොරියානු සඳහා සම්මත කට්ටල දෙකේ Hangul, සරල චීන සඳහා Pinyin, තායිවාන් සඳහා Chewing හි සම්මත Zhuyin සැකැස්ම සහ හොංකොං සඳහා එහි අක්ෂර හැඩ සහිත Cangjie භාවිත වේ. ජපන් (US යතුරුපුවරුව) US සැකැස්මක Mozc ලබා දෙයි. Dvorak, Colemak හෝ AZERTY මඟින් ලතින් අකුරු ලියන විටත් Hangul, Zhuyin සහ Cangjie යතුරු සම්මත ස්ථානවල පවතී. දැනටමත් Hangul හෝ Chewing එක් කර ඇත්නම් _සැකසුම > ටයිප් කිරීම > ආදාන ක්‍රම_ යටතේ තේරීම ඉවත් කර නැවත තෝරා යතුරු මාරු කරන්න; Omarchy දැනට භාවිත කරන එන්ජිම වෙනස් නොකරයි.

ටයිප් කිරීම ලතින් ප්‍රකාරයෙන් අරඹයි. වින්‍යාස කළ ආදාන ක්‍රම හරහා හැරීමට `Super + I` ඔබන්න, සහ හැරීමට `Super + Shift + I` ඔබන්න. ලතින් අකුරුවලට ඒවා පින්යින් වැනි ආදාන ක්‍රමයකින් පිටත්වීමට `Shift` තනිවම තට්ටු කරන්න, Sogou, Microsoft Pinyin, සහ macOS ක්‍රියා කරන ආකාරයට ආපසු යාමට නැවත තට්ටු කරන්න; `Shift` සහ අකුරක් තවමත් විශාල අකුරක් ටයිප් කරයි. ජපන් යතුරුපුවරු වල, 全角/半角 ආදානය ටොගල් කරයි, 変換 එය සක්‍රීය කරයි, සහ 無変換 එය අක්‍රීය කරයි. කොරියානු සඳහා 한/영 මඟින් Hangul මාරු වන අතර 한자 මඟින් Hanja බවට පරිවර්තනය වේ. වෙන්වූ යතුරු තිබුණත් බොහෝ ලැප්ටොප් මෙන් Right Alt හා Right Ctrl යැවුවත් මෙය ක්‍රියා කරයි; එබැවින් මෙහි ඒවා සාමාන්‍ය වෙනස්කාරක නොවන අතර ඔබාගෙන කථනය F9 මතම පවතී. `Ctrl + Space` Tmux සහ Herdr සඳහා ලබාගත හැක; `Shift + CapsLock` රචනා යතුර ලෙස පවතී.

ඔබට යතුරුපුවරු පිරිසැලසුම් හෝ ඇතුලත් කිරීමේ ක්‍රම කිහිපයක් ඇති විට යතුරුපුවරු දර්ශකය තීරුවේ දකුණු පසින් දිස්වනු ඇත. ඇතුලත් කිරීමේ භාෂා මාරු කිරීමට එය ක්ලික් කරන්න; ජපන් හිරගානා සඳහා あ පෙන්නුම් කරයි. ජපන් අක්ෂර අනුදානම් ලෙස තේරීමට, ජපන් වෙත මාරු වන්න, `nihongo` වැනි වචනයක් ටයිප් කරන්න, ඉන්පසු Space දෙවරක් ඔබන්න. ඔබේ තේරීම පිළිගැනීමට Enter ඔබන්න. ඔබට බහුවිධ යතුරුපුවරු පිරිසැලසුම් ද ඇත්නම්, ඒවා හැරීමට දර්ශකය දකුණු-ක්ලික් කරන්න.

ස්ථාපනයේදී ලබාදෙන එකම තේරීම් වලින් ඉංග්‍රීසි සහ ප්‍රංශ වැනි පිරිසැලසුම් තෝරාගැනීමට _සැකසුම > ටයිපිං > යතුරුපුවරු පිරිසැලසුම්_ භාවිතා කරන්න. කුමන සංයුක හෝ එන්ජින් සක්‍රීය දැයි තෝරාගැනීමට _සැකසුම > ටයිපිං > ඇතුලත් කිරීමේ ක්‍රම_ භාවිතා කරන්න. තේරීම් දෙකම ඔබේ වත්මන් තේරීම් ලෙසට පරීක්ෂා කරමින් Omarchy මෙනුව ඇතුළත විවෘත වේ. තේරීමක් ටොගල් කිරීමට ක්ලික් කරන්න හෝ Enter ඔබන්න; සෑම වෙනසක්ම වහාම අදාළ වේ. ඇතුලත් කිරීමේ ක්‍රමයක් ඉවත් කිරීම එය අස්ථාපනයක නොමැතිව වටයෙන් ඒය ඉවත් කරයි; යතුරුපුවරුව ලබාගත හැක.

එකම තේරීම් විවෘත කිරීමට `omarchy setup keyboard` හෝ `omarchy setup input` ක්‍රියාත්මක කරන්න. විධාන රේඛාවෙන් එක් භාෂාවක් එක් කිරීමට, `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing`, `cangjie5` භාවිතා කරන්න. ඔබේ අභිරුචි මාරු කිරීමේ යතුරු ආරක්ෂා කරනු ලැබේ. විකල්ප එන්ජින් පිරිසැලසුම් හෝ යතුරු සඳහා, `omarchy pkg add fcitx5-configtool` සමඟ `fcitx5-configtool` ස්ථාපනය කර එය ටර්මිනලයකින් දියත් කරන්න. ආදාන භාෂාවක් තෝරාගැනීම මේස භාෂාව වෙනස් නොකරනු ඇත. Quick, Boshiamy සහ Array Cangjie සමඟ එකම පැකේජයේ ඇති අතර ආදාන ක්‍රම තේරීමේ පෙනේ. _සැකසුම > භාෂාව_ යටතේ ජපන්, කොරියානු හෝ චීන තේරීමෙන්, තවමත් ආදාන ක්‍රමයක් නැත්නම් එය එක් වේ.

ඇතුලත් කිරීම් ක්‍රමය හෝ යතුරුපුවරු පිරිසැලසුම් හරහා හැරීමට `Super + I` භාවිතා කරන්න, සහ අනෙක් දිශාවට යාමට `Super + Shift + I` භාවිතා කරන්න, එවිට තුනක් වින්‍යාස කර ඇති විට ඔබට අසල්වැසියන් දෙදෙනෙකු අතර සංචලනය විය හැක. එකක් වැඩි ආදාන ක්‍රමයක් හෝ පිරිසැලසුමක් වින්‍යාස කර ඇති විට පමණක් ආදාන දර්ශකය තීරුවේ දකුණු පස දිස්වේ. මෙම මේස බන්ධනය ඔබේ පවතින Fcitx මාරු කිරීමේ යතුරු අසලම ක්‍රියා කරන අතර; ඔබට එය `~/.config/hypr/bindings.lua` තුළ අවලංගු කළ හැක. ඇතුලත් කිරීමේ එන්ජින් සහ රචනා අනුක්‍රම එක් එක් සැසියේම දැනටමත් ක්‍රියාත්මක වන [Fcitx5](https://fcitx-im.org/) සේවාව භාවිතා කරයි.

### ALT එක SUPER එක ලෙස භාවිතා කරන්න

```lua

  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
