# Mga Font

Ginagamit ng Omarchy ang JetBrainsMono Nerd Font bilang font ng terminal at font ng sistema bilang default.

 ![fonts-jetbrainsmono](images/fonts-jetbrainsmono.webp)

Maaari mo itong palitan sa pamamagitan ng menu na _Estilo > Font_ sa menu ng Omarchy (`Super + Space`). Itinatakda niyon ang monospace na font sa lahat ng dako: ang terminal, ang bar, at anumang iba pang humihingi nito.

Maaari kang mag-install ng iba pang sikat na font para sa programming sa pamamagitan ng _I-install > Estilo > Font_ sa menu ng Omarchy: ang Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono, at Iosevka ay pawang isang click na lang ang layo, sa kanilang mga bersyon na Nerd Font para patuloy na gumana ang mga glyph sa bar at terminal. Pagkatapos mag-install ng isa, piliin ito sa ilalim ng _Estilo > Font_.

## Tsino, Hapon, Koreano

Maraming karakter ang magkapareho sa Tsino, Hapon, at Koreano, ngunit naiiba ang hugis ng ilan. Itinatakda ng pagpili ng wika sa _Pag-setup > Wika_, o ng input method nito, ang katugmang mga anyo. Pumili sa _Estilo > Font > Tsino, Hapon, Koreano_ o gamitin ang `omarchy font cjk jp`, `kr`, `sc`, `tc` (Taiwan), o `hk` (Hong Kong) sa terminal. Ibinabalik ng `omarchy font cjk default` ang pinili ng system: mga anyong Hapon. Pinananatili ng tekstong may sariling wikang itinakda ng pahina o dokumento ang mga anyo ng wikang iyon, pati ng buong desktop kapag nasa isa sa mga wikang ito.
