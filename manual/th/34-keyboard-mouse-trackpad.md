# แป้นพิมพ์ เมาส์ แทร็กแพด

Hyprland ให้คุณกำหนดค่าอินพุตทั้งหมดของคุณอย่างละเอียดมาก คุณเปลี่ยนการซ้ำแป้นพิมพ์ให้เร็วเหนือเสียง หรือทำให้แทร็กแพดใช้การเลื่อนแบบธรรมชาติได้ คุณเปลี่ยนทั้งหมดได้ใน `~/.config/hypr/input.lua` ซึ่งเข้าถึงได้ผ่าน _ตั้งค่า > อินพุต_ ในเมนู Omarchy (`Super + Space`) อะไรก็ตามที่คุณตั้งไว้ที่นั่นจะแทนที่ค่าเริ่มต้นของ Omarchy

นี่คือตัวอย่าง:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

คุณสามารถ [ดูตัวเลือกอินพุตทั้งหมด](https://wiki.hypr.land/Configuring/Basics/Variables/#input) ได้บนวิกิ Hyprland สำหรับอินพุต

CapsLock ทำงานเป็น Caps Lock ปกติ และ `Shift + CapsLock` คือปุ่ม compose สำหรับ [อีโมจิแบบด่วน](07-hotkeys.md#quick-emojis) และ [การเติมอื่น ๆ](07-hotkeys.md#quick-completions) ถ้าคุณอยากให้ปุ่ม compose อยู่ที่อื่นมากกว่า ให้แทนที่ `omarchy:shift_caps_compose` ใน `kb_options` ตัวอย่างเช่น ตัวนี้ย้ายปุ่ม compose ไป Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### ท่าทางแทร็กแพด

คุณยังเปิด [ท่าทางทัชแพด](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) ได้ เช่น ปัดด้วยสามนิ้วเพื่อเปลี่ยนพื้นที่งาน:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

บนแล็ปท็อป Dell XPS ที่มีทัชแพดแบบแฮปติก คุณยังตั้งกำลังคลิกเป็นต่ำ กลาง หรือสูงได้ที่ _สั่งการ > ฮาร์ดแวร์ > การสั่นทัชแพด_

### การพิมพ์ในภาษาจีน ญี่ปุ่น และภาษาอื่น ๆ

เมื่อโปรแกรมติดตั้งถามแป้นพิมพ์ ให้เลือกญี่ปุ่น เกาหลี จีน (ตัวย่อ, Pinyin) ไต้หวัน (Zhuyin) หรือฮ่องกง (Cangjie) Omarchy จะตั้งค่าแป้นพิมพ์และเอนจินป้อนข้อมูลให้อัตโนมัติ รวมถึงการเริ่มต้นครั้งแรกแบบออฟไลน์ ญี่ปุ่นใช้ Mozc เกาหลีใช้ Hangul สองชุดมาตรฐาน จีนตัวย่อใช้ Pinyin ไต้หวันใช้ผัง Zhuyin มาตรฐานของ Chewing และฮ่องกงใช้ Cangjie พร้อมรูปอักษรฮ่องกง ญี่ปุ่น (แป้นพิมพ์ US) ให้ Mozc กับผัง US ปุ่ม Hangul, Zhuyin และ Cangjie ยังคงอยู่ตำแหน่งมาตรฐานแม้พิมพ์อักษรละตินด้วย Dvorak, Colemak หรือ AZERTY หากเคยเพิ่ม Hangul หรือ Chewing แล้ว ให้ยกเลิกและเลือกใหม่ที่ _ตั้งค่า > การพิมพ์ > วิธีป้อนข้อมูล_ เพื่อย้ายปุ่ม Omarchy จะไม่เปลี่ยนเอนจินที่ใช้อยู่แล้ว

การพิมพ์เริ่มในโหมดละติน กด `Super + I` เพื่อวนผ่านวิธีป้อนข้อมูลที่กำหนดค่าไว้ และ `Super + Shift + I` เพื่อวนกลับ แตะ `Shift` ด้วยตัวเองเพื่อก้าวออกจากวิธีป้อนข้อมูลอย่างพินอินไปเป็นตัวอักษรละติน และแตะมันอีกครั้งเพื่อกลับไป ในแบบที่ Sogou, Microsoft Pinyin และ macOS ทำงาน `Shift` บวกตัวอักษรยังพิมพ์ตัวพิมพ์ใหญ่ บนแป้นพิมพ์ภาษาญี่ปุ่น 全角/半角 สลับอินพุต 変換 เปิดมัน และ 無変換 ปิดมัน เมื่อใช้เกาหลี 한/영 สลับ Hangul และ 한자 แปลงเป็น Hanja ไม่ว่าจะมีปุ่มเฉพาะหรือแป้นพิมพ์ส่ง Right Alt และ Right Ctrl เหมือนแล็ปท็อปหลายรุ่น ดังนั้นสองปุ่มนี้จึงไม่ใช่ปุ่มปรับแต่งธรรมดาที่นี่ ส่วนการกดค้างเพื่อพูดป้อนข้อความยังอยู่ที่ F9 `Ctrl + Space` ยังคงมีให้สำหรับ Tmux และ Herdr `Shift + CapsLock` ยังคงเป็นปุ่ม compose

ตัวชี้วัดแป้นพิมพ์ปรากฏทางขวาของแถบเมื่อคุณมีเค้าโครงแป้นพิมพ์หรือวิธีป้อนข้อมูลหลายแบบ คลิกมันเพื่อสลับภาษาอินพุต ภาษาญี่ปุ่นแสดง あ สำหรับฮิรางานะ สำหรับการเลือกตัวอักษรภาษาญี่ปุ่น ให้สลับไปภาษาญี่ปุ่น พิมพ์คำอย่าง `nihongo` แล้วกด Space สองครั้ง กด Enter เพื่อยอมรับสิ่งที่คุณเลือก ถ้าคุณมีเค้าโครงแป้นพิมพ์หลายแบบด้วย ให้คลิกขวาที่ตัวชี้วัดเพื่อวนผ่านพวกมัน

ใช้ _ตั้งค่า > การพิมพ์ > เค้าโครงแป้นพิมพ์_ เพื่อเลือกเค้าโครงอย่างภาษาอังกฤษและภาษาฝรั่งเศส จากตัวเลือกเดียวกันที่เสนอระหว่างการติดตั้ง ใช้ _ตั้งค่า > การพิมพ์ > วิธีป้อนข้อมูล_ เพื่อเลือกว่าเอนจินการประกอบใดใช้งานอยู่ ตัวเลือกทั้งสองเปิดภายในเมนู Omarchy พร้อมสิ่งที่คุณเลือกปัจจุบันซึ่งทำเครื่องหมายไว้ คลิกหรือกด Enter เพื่อสลับตัวเลือก แต่ละการเปลี่ยนแปลงมีผลทันที การยกเลิกเลือกวิธีป้อนข้อมูลจะลบมันออกจากวงวนโดยไม่ถอนการติดตั้ง แป้นพิมพ์ยังคงมีอยู่

รัน `omarchy setup keyboard` หรือ `omarchy setup input` เพื่อเปิดตัวเลือกเดียวกัน หากต้องการต่อท้ายหนึ่งภาษาจากคอมมานด์ไลน์ ให้ใช้ `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing`, `cangjie5` ปุ่มสลับแบบกำหนดเองของคุณจะถูกเก็บไว้ สำหรับเค้าโครงหรือปุ่มเอนจินทางเลือก ให้ติดตั้ง `fcitx5-configtool` ด้วย `omarchy pkg add fcitx5-configtool` แล้วเปิดมันจากเทอร์มินัล การเลือกภาษาอินพุตไม่ได้เปลี่ยนภาษาเดสก์ท็อป Quick, Boshiamy และ Array อยู่ในแพ็กเกจเดียวกับ Cangjie และปรากฏในตัวเลือกวิธีป้อนข้อมูล การเลือกญี่ปุ่น เกาหลี หรือจีนที่ _ตั้งค่า > ภาษา_ จะเพิ่มวิธีป้อนข้อมูลหากยังไม่มี

ใช้ `Super + I` เพื่อวนผ่านวิธีป้อนข้อมูลหรือเค้าโครงแป้นพิมพ์ และ `Super + Shift + I` เพื่อกลับไปอีกทาง ดังนั้นด้วยสามแบบที่กำหนดค่าไว้ คุณจึงเคลื่อนระหว่างเพื่อนบ้านสองรายกันได้ ตัวชี้วัดอินพุตปรากฏทางขวาของแถบเฉพาะเมื่อมีการกำหนดค่าวิธีป้อนข้อมูลหรือเค้าโครงมากกว่าหนึ่งแบบเท่านั้น การผูกเดสก์ท็อปนี้ทำงานควบคู่ไปกับปุ่มสลับ Fcitx ที่มีอยู่ของคุณ คุณแทนที่มันได้ใน `~/.config/hypr/bindings.lua` เอนจินอินพุตและลำดับ compose ใช้บริการ [Fcitx5](https://fcitx-im.org/) ที่รันอยู่แล้วในทุกเซสชัน

### ใช้ ALT เป็น SUPER

บนแป้นพิมพ์บางตัว มันไม่สะดวกที่จะใช้ปุ่ม meta หลัก (ปุ่ม Windows/cmd) เป็น SUPER คุณสามารถเปลี่ยนสิ่งนี้ให้เป็น ALT แทนได้โดยใช้การเปลี่ยนแปลงนี้:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
