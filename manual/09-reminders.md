# Reminders

Maslow OS has a built-in way to set simple countdown reminders with a message. Use `Super + Ctrl + R`, view active reminders with `Super + Ctrl + Alt + R`, and clear them with `Super + Ctrl + Shift + R`. The same actions are under _Trigger > Reminder_, or use the compatible CLI with `omarchy reminder 7 'Tea ready'`.
