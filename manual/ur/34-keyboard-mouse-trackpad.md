# کی بورڈ، ماؤس، ٹریک پیڈ

Hyprland آپ کو اپنے تمام ان پٹ کو بڑی تفصیل سے ترتیب دینے دیتا ہے। آپ کی بورڈ دہرائی کو انتہائی تیز کر سکتے ہیں یا ٹریک پیڈ کو فطری اسکرولنگ استعمال کرنے پر مجبور کر سکتے ہیں। آپ اس سب کو `~/.config/hypr/input.lua` میں تبدیل کرتے ہیں، جس تک آپ Omarchy مینو (`Super + Space`) میں _سیٹ اپ > ان پٹ_ کے ذریعے بھی پہنچ سکتے ہیں। وہاں آپ جو کچھ بھی مقرر کرتے ہیں وہ Omarchy کے ڈیفالٹس کی جگہ لے لیتا ہے।

یہاں ایک مثال है:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

آپ Hyprland ویکی پر ان پٹ के لیے [تمام ان پٹ اختیارات دیکھ سکتے ہیں](https://wiki.hypr.land/Configuring/Basics/Variables/#input)۔

CapsLock عام Caps Lock کے طور پر کام करता है، اور `Shift + CapsLock` [فوری ایموجیز](07-hotkeys.md#quick-emojis) اور [دیگر تکمیلات](07-hotkeys.md#quick-completions) کے لیے کمپوز کلید ہے। اگر آپ کمپوز کلید کہیں اور رکھنا پسند کریں تو `kb_options` میں `omarchy:shift_caps_compose` کو تبدیل کردیں। مثال کے طور پر، یہ کمپوز کلید کو دائیں Alt پر منتقل करता है:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### ٹریک پیڈ اشارے

آپ [ٹچ پیڈ اشاروں](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/) کو بھی آن کر سکتے हैं، جیسے ورک اسپیس تبدیل کرنے کے لیے تین انگلیوں سے سوائپ کرنا:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

ہیپٹک ٹچ پیڈ والے Dell XPS لیپ ٹاپ پر، آپ _ٹریگر > ہارڈویئر > ٹچ پیڈ ہیپٹکس_ کے تحت کلک کی طاقت کو کم، درمیانی یا زیادہ بھی مقرر कर سکتے ہیں।

### چینی، جاپانی اور دیگر زبانوں میں ٹائپ کرنا

انسٹالر کی بورڈ پوچھے تو جاپانی، کوریائی، چینی (سادہ، Pinyin)، تائیوان (Zhuyin) یا ہانگ کانگ (Cangjie) چنیں۔ Omarchy پہلے آف لائن آغاز میں بھی کی بورڈ اور ان پٹ انجن خود ترتیب دیتا ہے۔ جاپانی Mozc، کوریائی معیاری دو سیٹ Hangul، سادہ چینی Pinyin، تائیوان Chewing کی معیاری Zhuyin ترتیب اور ہانگ کانگ مقامی حروف کی شکلوں والا Cangjie استعمال کرتا ہے۔ جاپانی (US کی بورڈ) US ترتیب کے ساتھ Mozc دیتا ہے۔ Dvorak، Colemak یا AZERTY سے لاطینی حروف لکھتے وقت بھی Hangul، Zhuyin اور Cangjie کیز اپنی معیاری جگہ رہتی ہیں۔ اگر Hangul یا Chewing پہلے شامل کیا ہے تو _سیٹ اپ > ٹائپنگ > ان پٹ طریقے_ میں اسے ہٹا کر دوبارہ چنیں تاکہ کیز منتقل ہوں؛ Omarchy پہلے سے استعمال ہونے والا انجن نہیں بدلتا۔

ٹائپنگ لاطینی موڈ میں شروع ہوتی ہے। ترتیب شدہ ان پٹ میتھڈز میں گردش کرنے کے لیے `Super + I` دبائیں، اور پیچھے گردش کرنے کے لیے `Super + Shift + I` دبائیں। پِنین جیسے ان پٹ میتھڈ سے لاطینی حروف میں باہر نکلنے کے لیے `Shift` کو تنہا دبائیں، اور واپس جانے کے لیے اسے دوبارہ دبائیں، جس طرح Sogou، Microsoft پِنین، اور macOS کرتے ہیں؛ `Shift` اور حرف کا مجموعہ اب بھی بڑا حرف ٹائپ کرتا ہے۔ جاپانی کی بورڈز پر، 全角/半角 ان پٹ کو ٹوگل کرتا ہے، 変換 اسے آن کرتا ہے، اور 無変換 اسے آف کرتا ہے। کوریائی میں 한/영 سے Hangul بدلتا اور 한자 سے Hanja میں تبدیلی ہوتی ہے، چاہے الگ کیز ہوں یا بہت سے لیپ ٹاپ کی طرح کی بورڈ Right Alt اور Right Ctrl بھیجے؛ اس لیے یہاں یہ عام موڈیفائر نہیں اور دبا کر بولنے والا ڈکٹیشن F9 پر رہتا ہے۔ `Ctrl + Space` Tmux اور Herdr کے لیے دستیاب रहتی है؛ `Shift + CapsLock` کمپوز کلید کے طور پر برقرار رہتی ہے।

کی بورڈ اشارے بار کے دائیں طرف ظاہر ہوتا ہے جب آپ کے پاس متعدد کی بورڈ لے آؤٹ یا ان پٹ میتھڈ ہوں। ان پٹ زبانیں بدلنے کے لیے اس پر کلک کریں؛ جاپانی ہیراگنا کے لیے あ دکھاتی ہے। جاپانی حروف کے انتخاب کے لیے، جاپانی میں سوئچ کریں، `nihongo` جیسا لفظ ٹائپ کریں، پھر Space کو دو बार دبائیں। اپنا انتخاب قبول کرنے کے لیے Enter دبائیں। اگر آپ کے پاس متعدد کی بورڈ لے آؤٹ بھی ہیں تو اشارے پر دایاں کلک کر کے ان میں گردش کریں।

انگریزی اور فرانسیسی جیسے لے آؤٹ منتخب کرنے کے لیے _سیٹ اپ > ٹائپنگ > کی بورڈ لے آؤٹس_ استعمال کریں، انہی انتخاب سے جو انسٹالیشن کے دوران پیش کیے جاتے ہیں। کون سے تحریری انجن فعال ہیں یہ منتخب کرنے کے لیے _سیٹ اپ > ٹائپنگ > ان پٹ میتھڈز_ استعمال کریں। دونوں منتخب کنندگان Omarchy مینو کے اندر کھلتے ہیں جن میں آپ کے موجودہ انتخاب چیک ہوتے ہیں। انتخاب کو ٹوگل کرنے کے لیے کلک کریں یا Enter دبائیں؛ ہر تبدیلی فوری طور پر لاگو ہوتی ہے। ان پٹ میتھڈ کو غیر منتخب کرنے سے یہ انسٹال ہوئے بغیر سائیکل سے ہٹا दिया جاتا है؛ کی بورڈ دستیاب رہتا ہے।

وہی منتخب کنندگان کھولنے کے لیے `omarchy setup keyboard` یا `omarchy setup input` چلائیں। کمانڈ لائن سے ایک زبان شامل کرنے کے لیے، `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing`, `cangjie5` استعمال کریں। آپ کی اپنی مرضی کی سوئچنگ کلیدیں برقرار رکھیں जाती ہیں। متبادل انجن لے آؤٹ یا کلیدوں کے لیے، `omarchy pkg add fcitx5-configtool` کے ساتھ `fcitx5-configtool` انسٹال کریں اور اسے ٹرمینل سے شروع کریں। ان پٹ زبان منتخب کرنے سے ڈیسک ٹاپ زبان تبدیل نہیں ہوتی। Quick، Boshiamy اور Array، Cangjie کے اسی پیکیج میں آتے ہیں اور ان پٹ طریقے کے انتخاب میں نظر آتے ہیں۔ _سیٹ اپ > زبان_ میں جاپانی، کوریائی یا چینی چننے سے، اگر کوئی طریقہ نہیں تو وہ شامل ہو جاتا ہے۔

ان پٹ میتھڈز یا کی بورڈ لے آؤٹ میں گردش کرنے کے لیے `Super + I` استعمال کریں، اور دوسری سمت واپس جانے کے لیے `Super + Shift + I` استعمال کریں، لہٰذا تین ترتیب شدہ کے साथ آپ دو پڑوسیوں کے درمیان منتقل हो सकते हैं। ان پٹ اشارہ بار کے دائیں طرف صرف اسی وقت ظاہر ہوتا ہے جب ایک سے زیادہ ان پٹ میتھڈ یا لے آؤٹ ترتیب شدہ ہو। یہ ڈیسک ٹاپ بائنڈنگ آپ کی موجودہ Fcitx سوئچنگ کلیدوں کے شان باندھ کر کام کرتی ہے؛ آپ اسے `~/.config/hypr/bindings.lua` میں اووررائڈ کر سکتے ہیں। ان پٹ انجن اور کمپوز ترتیبیں اس سیشن میں پہلے ہی چل رہی [Fcitx5](https://fcitx-im.org/) سروس کا استعمال کرتی ہیں।

### SUPER کے طور پر ALT استعمال کریں

کچھ کی بورڈ پر، بنیادی میٹا کلید (Windows/cmd کلید) کو SUPER کے طور پر استعمال کرنا آسان نہیں होता। آپ یہ تبدیلی استعمال کر کے اسے اس کی جگہ ALT میں بدل सकते ہیں:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
