# Клавіатура, миша, трекпад

Hyprland дозволяє конфігурувати всі ваші входи з великою деталізацією. Ви можете змінити повторення клавіатури, щоб зробити його надзвуково швидким, або змусити трекпад використовувати природне прокручування. Усе це ви змінюєте в `~/.config/hypr/input.lua`, до якого також можна дістатися через _Налаштування > Введення_ в меню Omarchy (`Super + Space`). Будь-що, що ви там виставите, замінює типові налаштування Omarchy.

Ось приклад:

```lua
hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "omarchy:shift_caps_compose,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })
```

Ви можете [побачити всі опції введення](https://wiki.hypr.land/Configuring/Basics/Variables/#input) у вікі Hyprland щодо входів.

CapsLock працює як звичайний Caps Lock, а `Shift + CapsLock` є композиційною клавішею для [швидких емоджі](07-hotkeys.md#quick-emojis) і [інших доповнень](07-hotkeys.md#quick-completions). Якщо ви волієте композиційну клавішу деінде, замініть `omarchy:shift_caps_compose` у `kb_options`. Наприклад, це переміщує композиційну клавішу на Right Alt:

```lua
hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})
```

### Жести трекпада

Ви також можете увімкнути [жести тачпада](https://wiki.hypr.land/Configuring/Advanced-and-Cool/Gestures/), як-от проведення трьома пальцями для зміни робочих просторів:

```lua
hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })
```

На ноутбуках Dell XPS із тактильним тачпадом ви також можете встановити силу кліку на низьку, середню чи високу в розділі _Дії > Обладнання > Вібрація тачпада_.

### Набір тексту китайською, японською та іншими мовами

Коли інсталятор запитує клавіатуру, виберіть японську, корейську, китайську (спрощену, Pinyin), Тайвань (Zhuyin) або Гонконг (Cangjie). Omarchy автоматично налаштовує клавіатуру й рушій введення, також при першому запуску без мережі. Японська використовує Mozc, корейська — стандартний двонабірний Hangul, спрощена китайська — Pinyin, Тайвань — стандартну розкладку Zhuyin у Chewing, а Гонконг — Cangjie з гонконзькими формами ієрогліфів. Японська (US-клавіатура) дає Mozc з розкладкою US. Клавіші Hangul, Zhuyin і Cangjie залишаються на стандартних місцях навіть при латинці з Dvorak, Colemak або AZERTY. Якщо Hangul або Chewing вже додано, зніміть і повторіть вибір у _Налаштування > Набір тексту > Методи введення_, щоб перемістити клавіші; Omarchy не змінює вже вживаний рушій.

Набір починається в латинському режимі. Натискайте `Super + I`, щоб циклічно переходити налаштовані методи введення, і `Super + Shift + I`, щоб циклічно повертатися назад. Торкніться самого лише `Shift`, щоб вийти з методу введення на кшталт Pinyin до латинських літер, і торкніться ще раз, щоб повернутися, так само як працюють Sogou, Microsoft Pinyin та macOS; `Shift` плюс літера й далі набирає велику літеру. На японських клавіатурах 全角/半角 перемикає введення, 変換 вмикає його, а 無変換 вимикає його. У корейській 한/영 перемикає Hangul, а 한자 перетворює на Hanja, і з окремими клавішами, і коли клавіатура, як багато ноутбуків, надсилає Right Alt та Right Ctrl; тому тут це не звичайні модифікатори, а диктування з утриманням залишається на F9. `Ctrl + Space` лишається доступним для Tmux і Herdr; `Shift + CapsLock` лишається композиційною клавішею.

Індикатор клавіатури зʼявляється праворуч на панелі, коли у вас кілька розкладок клавіатури чи методів введення. Натисніть його, щоб перемкнути мови введення; для японської показується あ для хірагани. Для вибору японських символів перемкніться на японську, наберіть слово, як-от `nihongo`, потім двічі натисніть Space. Натисніть Enter, щоб прийняти свій вибір. Якщо у вас також кілька розкладок клавіатури, клацніть індикатор правим кліком, щоб циклічно їх переходити.

Використовуйте _Налаштування > Набір тексту > Розкладки клавіатури_, щоб вибрати розкладки на кшталт англійської та французької, з тих самих варіантів, що пропонуються під час встановлення. Використовуйте _Налаштування > Набір тексту > Методи введення_, щоб вибрати, які рушії композиції активні. Обидва вибірники відкриваються всередині меню Omarchy з позначеними вашими поточними виборами. Клацніть або натисніть Enter, щоб перемкнути вибір; кожна зміна застосовується миттєво. Зняття вибору методу введення прибирає його з циклу, не деінсталюючи його; клавіатура лишається доступною.

Виконайте `omarchy setup keyboard` або `omarchy setup input`, щоб відкрити ті самі вибірники. Щоб додати одну мову з командного рядка, використовуйте `omarchy setup input mozc`, `hangul`, `pinyin`, `chewing`, `cangjie5`. Ваші власні клавіші перемикання зберігаються. Для альтернативних розкладок чи клавіш рушіїв встановіть `fcitx5-configtool` командою `omarchy pkg add fcitx5-configtool` і запустіть його з термінала. Вибір мови введення не змінює мови робочого столу. Quick, Boshiamy і Array входять до пакунка Cangjie й з'являються у виборі методів введення. Вибір японської, корейської чи китайської в _Налаштування > Мова_ додає метод введення, якщо ще жодного немає.

Використовуйте `Super + I`, щоб циклічно переходити методи введення чи розкладки клавіатури, і `Super + Shift + I`, щоб піти назад іншим шляхом, тож із трьома налаштованими ви можете рухатися між двома сусідами. Індикатор введення зʼявляється праворуч на панелі лише тоді, коли налаштовано більше одного методу введення чи розкладки. Це привʼязування на робочому столі працює разом із вашими наявними клавішами перемикання Fcitx; ви можете перевизначити його в `~/.config/hypr/bindings.lua`. Рушії введення й композиційні послідовності використовують службу [Fcitx5](https://fcitx-im.org/), яка вже працює в кожному сеансі.

### Використовуйте ALT як SUPER

На деяких клавіатурах незручно використовувати основну мета-клавішу (клавішу Windows/cmd) як SUPER. Ви можете змінити це на ALT натомість такою зміною:

```lua
hl.config({
  input = {
    kb_options = "omarchy:shift_caps_compose,altwin:swap_alt_win",
  },
})
```
